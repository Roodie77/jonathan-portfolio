Live API / attack it yourself

Xeno Shield API.

A defensive API for websites and apps. It does two jobs: quarantine bad data before it reaches your database (SQL injection, XSS, path traversal, log4shell, obfuscated payloads, even encoded evasions), and stop abuse before it reaches your users (brute force, credential stuffing, password spraying, distributed attacks) with bans that escalate on repeat offenders. It runs entirely in your browser and speaks real HTTP semantics. Fire the recipes, launch a simulated attack, edit anything, or open devtools and call xeno.fetch('/v1/quarantine').

  • 8 detector families
  • Evasion-proof (URL-decode, Unicode)
  • Reviewer state machine
  • Brute force + stuffing + spray
  • Escalating bans
  • Tunable policies
  • ETag + If-Match
  • RFC 9457 errors
  • Idempotency-Key
  • Keyset pagination

Live API / insurance claims

        
Roodie Insuretech API.

        
How an insurer actually handles a claim, as an API. File a claim and the engine checks the policy (active, in force, waiting period, coverage, exclusions, filing window), works out what would be payable after the deductible, coinsurance and remaining limit, scores it for fraud with every red flag spelled out, then routes it: straight-through approval, an adjuster, special investigations, or automatic denial. Adjusters decide and pay; claimants edit, appeal and withdraw. I built it because I study insurance and write backends, and this is where the two meet. Click a claim to see why it was routed the way it was, or run a scenario.
